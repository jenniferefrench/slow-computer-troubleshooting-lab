# Slow Computer Troubleshooting Lab

## Scenario

A user reports that their Windows computer is running slowly and affecting their productivity.

## Step 1: Gather System Information

I would first check the computer's CPU, RAM, storage type, and storage capacity.

## Step 2: Check Software Requirements

I would compare the computer's hardware specifications with the requirements for Microsoft 365 applications such as Word, Excel, PowerPoint, and Teams.

## Step 3: Identify the Bottleneck

I would use Task Manager to check CPU, memory, disk, and running processes to see which resource is causing the slowdown.

## Step 4: Findings

Task Manager showed RAM usage at 94%, which indicated that RAM was the performance bottleneck.

## Step 5: Troubleshooting Solution

I would first close unnecessary applications and browser tabs to reduce RAM usage.

## Step 6: Hardware Upgrade

If RAM usage remains high after closing unnecessary applications, I would recommend upgrading the computer's RAM.

## Step 7: Test the Solution

After making the changes, I would use Task Manager again to monitor CPU, memory, disk, and application performance to confirm that the computer is running better.

## Step 8: Ongoing Support

I would recommend regular system maintenance, keeping software updated, and teaching the user to close unnecessary applications when they are not in use.

## What I Learned
